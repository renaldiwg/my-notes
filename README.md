# My Notes

A simple notes application built using HTML, Tailwind CSS, and jQuery.

## Features

- Add new notes
- Edit existing notes
- Delete notes
- Cancel editing
- Responsive layout

## Technologies Used

- HTML
- Tailwind CSS
- JavaScript
- jQuery

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Start creating your notes!

## Notes

Notes are currently stored in the page's DOM and will be lost when the page is refreshed.
